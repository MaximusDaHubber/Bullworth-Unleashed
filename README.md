# Bullworth Unleashed

A huge all-in-one mod for **Bully: Scholarship Edition** (PC) with a **15-page in-game mod menu**: superpowers, zombie mode with custom zombie skins, a spawner with the boss-fight versions of every boss, Hitman contracts, a GTA wanted system, shop heists, Boss Rush, Gang Wars with a live turf map, a brand-new Hitman suit and more.

## Download

Get the latest zip from the **[Releases](../../releases)** page.

## Requirements

- Bully: Scholarship Edition (PC)
- **Derpy's Script Loader (DSL) 16 or newer** - install this first
- Recommended: **SilentPatch for Bully** (not required)

## Install

1. Close Bully.
2. Extract the zip into your Bully folder (the one with `Bully.exe`). Nothing of the game is replaced.
3. Optional: run `BullworthUnleashed\Install Hitman suit.bat` once to make the Hitman suit wearable.
4. Start the game and open the menu: **M** on keyboard, **hold LT + Look Back** on controller.

The full controls and how every mode works are in `BullworthUnleashed\README.txt` inside the zip.

## What's included

**Sandbox tools**
- **Superpowers** - flight, super jump, super strength, god mode, slow motion, fire shockwave, telekinesis
- **Cheats** - infinite ammo, all weapons, money, carnival tickets, freeze time, any hairstyle, all collectibles
- **Teleport** - Rockstar's own debug teleport list
- **World** - time, weather (snow and Christmas snow too), holiday decorations
- **Play as** - play as other characters, fighting works with all of them
- **Outfits** - the game's special outfits, the new Hitman suit and the **wardrobe anywhere**
- **Vehicles** - bikes, karts, cars and the 3D arcade ships
- **Spawner** - friends, enemies, group fights and the boss-fight versions of the story bosses

**Game modes**
- **Arcade** - Rockstar's hidden full 3D version of the arcade race
- **GTA Wanted System** - 1 to 5 stars with prefects, cops, orderlies and the Principal
- **Zombie Mode** - waves of zombies at night with zombie bosses
- **Hitman: Bullworth** - contracts, disguises and Silent Assassin ratings
- **Heists** - hold up shops, then escape the cops to keep the cash
- **Boss Rush** - all 7 story bosses back to back in Russell's pit
- **Gang Wars** - join a clique and take Bullworth district by district
